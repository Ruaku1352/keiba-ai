# v17：スマホ用のウェブアプリ画面（Google Apps Script）

PC は今までどおりシートに書くだけ。画面用のデータを書くタブ「app_data」を1つ足し、シートに付けた Apps Script がそれを読んで、
スマホ向けの画面として表示する。自宅の PC を外から見えるようにする仕組み（サーバー・トンネル）は使わない。

- 当日の計算（買い目・付け替え・保存される JSON）は変えていない
- 画面用のデータを書けなくても、買い目の保存と、「当日の買い目」「スマホ」のタブへの書き込みは先に終わっている
- 「スマホ」タブは、ウェブアプリが開けないときの予備として残す（v17 で色を薄い背景＋濃い文字に直した）
- リポジトリには、シート ID もウェブアプリの URL も入れない（スクリプトはシートに紐づけて `getActiveSpreadsheet()` で読む）

## 仕組み

| どこ | 何をする |
|---|---|
| PC（`src/raceday.py`） | タブ「app_data」の A1:A20 に、画面に必要な内容を JSON で書く（4万字ずつに分ける。文字のまま＝RAW。シートへの書き込みは1回）。手元にも `data\raceday\app_data.json` |
| `apps_script/Code.gs` | タブを読んで、つないだ文字を返すだけ（薄い） |
| `apps_script/index.html` | 表示のロジックは全部ここ（JavaScript）。30 秒ごとに読み直す |

書くとき：`update` の各回、`sheet --date`、`score --sheet`・`practice --sheet`（この2つは成績のところだけを新しくする）。

中身：日付、最終更新の時刻（`2026-11-22T15:20:05+09:00`）、k・m、全体の警告（時計・ネット）、PC が止まっていた可能性、
レースごと（場・R・レース名・グレード・発走・状態・説明・作成時刻・警告・買い目［券種・組番・金額・元の金額・付け替えたか・推定配当・本物のオッズ・当たったときの払戻］・
点数・合計・予測の達成確率・当日の傾向を使えたか・使ったレース・オッズの発表・熱さ・仮の買い目）、成績（通算と最近の重賞）。
組番は文字のまま（「6-8」「3→8→2」）。

状態の名前：最終／仮／途中／予備／オッズ待ち（発売前でまだ買い目なし）／買い目なし／最終を作れていない。発走済みかどうかは別の印（画面でも、発走時刻とスマホの時計から判断する）。

## 画面

- 左上の三本線のメニューで切り替える。最初に開くのは「当日の買い目」
  - **当日の買い目**：レースごとのカード（発走の早い順）。レース名と発走時刻 → 状態のバッジと説明 → 警告（あるときだけ）→ 買い目（券種・組番・金額）→ 合計と「7 / 13 点 入力済み」→ 予測の達成確率（小さく）。
    発走済みのレースは1行にたたむ（タップで開く）
  - **くわしい情報**：買い目ごとの推定配当・本物のオッズ・当たったときの払戻・付け替えの元の金額、当日の傾向と使ったレース、オッズの発表時刻、熱さ（参考）、仮の買い目
  - **成績**：F の本番・同じレースの6頭BOX・練習（平場・重賞）の通算と、最近の重賞
  - **仕組みの状態**：最終更新の時刻、最終更新から何分か、k・m、時計やネットの警告、PC が止まっていた可能性
- 上の帯（緑）の右に「更新 15:20・3分前」。その下に警告の帯：
  「最終更新から ○分。15分を超えました」（まだ発走していないレースがあるときだけ）、「更新できていない（最後に読めたのは ○:○）」、時計・ネットの警告。
  警告の帯は、メニューを開いていても隠れない
- 読み直しに失敗したら、前の表示を残したまま「更新できていない」と出す
- 入力済みの印：買い目の行をタップ。スマホのブラウザの中（localStorage）だけに保存し、シートには書かない。
  買い目・状態・作成時刻のどれかが変わったら（仮 → 最終 など）、そのレースの印は消える。最終のあとは変わらないので消えない
- 色：背景は白〜ごく薄い緑、文字は濃い灰色。状態は小さなバッジとカードの左の細い帯で示す（広い面を塗らない）。
  「最終」は緑＋チェックの印（✓ 最終）＋枠線、「仮」は黄系、「予備」は橙系、警告は薄い赤の背景に濃い赤の文字。ダークモードの配色もある。
  全体は芝を思わせる深い緑が基調。JRA のロゴ・名称・マーク・公式の画面の作りは使っていない

## PC のブラウザで見る見本（Apps Script を通さない）

同じ `index.html` に見本のデータを埋め込んだ HTML を書き出す。シートには書かない。買い目も作り直さない。

```
py -m src.raceday app-preview --open
```
各状態（最終・仮・途中・予備・最終を作れていない・まだ買い目なし・発走済み）の見本。`data\raceday\app_preview.html` に書き出してブラウザで開く。

```
py -m src.raceday app-preview --date 20261115 --now 1520 --open
```
その日の保存した買い目から（`--now` を省くと、その日の終わりの状態）。画面の中の「今」は、その時刻の1分後に止めてある。

スマホの幅で見るには、ブラウザで F12 →「デバイスのツールバー」（Ctrl+Shift+M）。ダークモードは、同じ画面の「レンダリング」か、PC の設定で。

## 設定の手順（1回だけ）

1. PC で1回、画面用のデータを書く（タブ「app_data」ができる）：`py -m src.raceday sheet --date 20261115`
2. スプレッドシートを PC のブラウザで開き、メニューの「拡張機能」→「Apps Script」を開く（新しいタブでエディタが開く）
3. 左のファイル一覧の「コード.gs」を開き、中身を全部消して、リポジトリの `apps_script\Code.gs` の中身を貼り付ける
4. ファイル一覧の「＋」→「HTML」を選び、名前を `index` にする（`.html` は自動で付く。名前は必ず `index`）。
   中身を全部消して、`apps_script\index.html` の中身を貼り付ける
5. 上のフロッピーの印（プロジェクトを保存）を押す
6. 右上の「デプロイ」→「新しいデプロイ」。「種類の選択」の歯車 →「ウェブアプリ」を選ぶ
   - 説明：何でもよい（例「v17」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
7. 「デプロイ」を押す。初回は「アクセスを承認」が出るので、自分の Google アカウントを選んで許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」。自分で作ったスクリプトなのでこの表示になる）
8. 出てきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーして、自分のスマホに送る
   （**この URL はリポジトリにもメモにも公開しない**。「自分のみ」なので、ほかの人が開いても見えないが、念のため）
9. スマホのブラウザ（シートと同じ Google アカウントでログインしていること）で URL を開く。買い目の画面が出れば OK
10. ホーム画面に追加する：iPhone（Safari）は共有ボタン →「ホーム画面に追加」。Android（Chrome）は右上の ︙ →「ホーム画面に追加」

### 画面を直したとき（`index.html` や `Code.gs` が変わったとき）

1. `git pull` のあと、Apps Script のエディタで `index`（と、変わっていれば `コード.gs`）の中身を全部消して、新しい中身を貼り付けて保存する
2. 「デプロイ」→「デプロイを管理」→ 鉛筆の印（編集）→「バージョン」を「**新バージョン**」にして「デプロイ」
   （「新しいデプロイ」ではなく、今のデプロイを編集する。こうすると URL が変わらず、ホーム画面のアイコンをそのまま使える）
3. スマホで画面を開き直す

PC 側のデータ（`app_data`）の形だけが変わったときは、貼り直しは要らない場合もあるが、`apps_script\` のファイルが変わっていたら貼り直す。

### うまくいかないとき

- 「データを読めていません：タブ app_data がまだありません」→ 手順 1 を先に
- 白い画面のまま・ログインを求められる → スマホのブラウザが、シートの持ち主の Google アカウントでログインしているか（複数のアカウントでログインしていると失敗することがある。その場合は持ち主のアカウントだけにする）
- 印が保存されない → ブラウザのプライベートモードでは保存されない。表示は動く
- ウェブアプリが開けないとき → 今までどおり、スプレッドシートの「スマホ」タブを見る

## 確かめたこと・確かめられていないこと

- PC 側（データの形・分け方・失敗しても他に影響しないこと・見本の HTML）はテストで確かめた
- `index.html` は、見本のデータを埋めた HTML をスマホの幅のブラウザ（Chromium）で開き、横スクロールが出ないこと、
  印を付けて読み直しても残ること、たたんだレースが開くこと、30 秒ごとの読み直し・失敗したときの表示・15 分を超えたときの警告（Apps Script の呼び出しを偽物に置き換えて）を確かめた
- **本物の Apps Script の上では動かしていない**（こちらでは動かせない）。`Code.gs` は 20 行ほどで、タブを読んで返すだけ
